# CSC1024-Semester 1 Group Work 

Project instructions: 

Social media is central to Gen Z life, from personal branding to content creation. This
project challenges you to build a Social Media Content Planner, a text-based application
that helps content creators plan, track, and analyse their posts across multiple
platforms. The system will manage post ideas, schedule content, track engagement
metrics, and generate performance summaries, all powered by Python and plain text
files.
